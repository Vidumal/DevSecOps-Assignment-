- 01-baseline/: vulnerable baseline commit/tag and application startup evidence.
- 02-sqli/ through 05-bola/: per-vulnerability before/after exploit and fix evidence.
- 06-sast/ through 09-container-scan/: scanner output and relevant screenshots.

Use descriptive filenames such as run-<id>-semgrep-before.txt or bola-after-response.png. Do not fabricate results; preserve the command, commit, or run ID needed to reproduce each result.
